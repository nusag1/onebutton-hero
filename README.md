# ワンボタン勇者

タップだけで冒険する、スマホ向けワンボタンアクション。

▶ https://nusag1.github.io/onebutton-hero/

## 遊び方
- 勇者ユウは自動で走る
- 地上でタップ → ジャンプ、空中でタップ → 急降下斬り
- 敵は上から踏むか急降下で倒す（急降下ならコイン2倍、空中で連続して倒すとコンボ）
- トゲ・穴・敵の横当たりでハートが減る。0で終了
- 集めたコインでショップの強化を買って、もっと遠くへ

## 特長
- キャラクターはすべてオリジナルのドット絵（コード内で1ドットずつ定義）
- 300m ごとにステージが変わる：草原 → 砂漠 → 洞窟 → 雪原 → 魔王城
- インストール不要。ホーム画面に追加すればオフラインでも遊べる（PWA）
